# Guided Lab 386.5.4 – Matplotlib Pyplot: Font Styling

## Overview

This lab demonstrates how to customize fonts in Matplotlib charts to create more readable and visually appealing visualizations. It covers styling chart titles and axis labels using keyword arguments and the `fontdict` parameter.

## Objectives

* Customize font properties in Matplotlib
* Change font family, size, color, and weight
* Style chart titles and axis labels
* Apply reusable font dictionaries
* Improve chart readability and presentation

## Technologies Used

* Python 3
* Matplotlib
* NumPy
* Google Colab / Jupyter Notebook

## Methods & Concepts

* `plt.plot()` – Create line charts
* `plt.title()` – Customize chart titles
* `plt.xlabel()` – Customize x-axis labels
* `plt.ylabel()` – Customize y-axis labels
* `fontweight` – Set text boldness
* `fontsize` – Adjust text size
* `fontfamily` – Specify the font family
* `color` – Change text color
* `fontdict` – Apply reusable font styling to titles and labels
* `plt.show()` – Display the completed visualization

## Key Points

* Font properties can be applied directly using keyword arguments.
* The `fontdict` parameter allows multiple font settings to be grouped into a reusable dictionary.
* Titles and axis labels can each have different font styles.
* Common font properties include family, size, color, and weight.
* Consistent font styling improves chart readability and creates more professional visualizations.

## Topics Covered

* Font customization
* Font families
* Font sizes
* Font colors
* Font weight (boldness)
* Keyword argument styling

* Title formatting
* Axis label formatting
